===和==的区别在vue3里面

# === (严格相等)

规则：先比较类型，再比较值。

结果：如果两边的数据类型不同，直接返回 false，绝对不会去猜你的意图。

# == (宽松相等) 隐式转换

规则：如果类型不同，先自动进行隐式类型转换（Type Coercion），把它们变成相同的类型，然后再比较值。

结果：这就会导致很多违反直觉的“神奇现象”。

| 表达式 | 使用 == 的结果 | 使用 === 的结果 | 原因解释 |
| ---- | ---- | ---- | ---- |
| 1 == '1' | true | false | == 会把字符串 '1' 悄悄转成数字 1 再对比；而 === 发现一个是数字一个是字符串，直接拒绝。 |
| null == undefined | true | false | 在 == 的规则里，它们俩被定义为相等。但它们分属不同的特殊类型，所以 === 为 false。 |
| 0 == false | true | false | == 会把布尔值 false 转成数字 0。 |
| 0 == '' | true | false | == 会把空字符串 '' 也转成数字 0。 |
