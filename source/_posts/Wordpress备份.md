# 推荐插件：All-in-One WP Migration


在你现在的 WordPress 后台 → 插件 → 安装 → 搜 All-in-One WP Migration


启用后，点导出 → 直接导出成一个 .wpress 单文件
（这个文件就是整站备份：文章、设置、图片、插件、数据库全在里面）


新服务器 / 新电脑搭建的空白 WP：

同样装这个插件 → 导入这个 .wpress 文件 → 一键还原

不用单独导 SQL，不用分开传文件
