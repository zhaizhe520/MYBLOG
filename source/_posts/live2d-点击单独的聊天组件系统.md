# 🛠️ 技术选型推荐
前端框架：Vue 3 (Composition API) + Vite (构建速度快，对现代 JS 支持好)

渲染引擎：PixiJS v7/v8

Live2D 插件：pixi-live2d-display (目前社区整合 Live2D 和 PixiJS 最成熟的库，支持 Cubism 2.1 和 4.x)

状态管理：Pinia (用于管理全局的聊天状态、看板娘状态)

样式库：Tailwind CSS (快速搞定聊天气泡和弹窗 UI)

# 📐 核心架构与核心逻辑
要实现“点击 Live2D 进入独立聊天组件”，核心在于 PixiJS 的事件监听 与 Vue 组件的状态通信。

核心步骤拆解
挂载 PixiJS 画布：在 Vue 的 onMounted 钩子中初始化 Pixi 应用，并加载 Live2D 模型。

监听点击事件：利用 pixi-live2d-display 自带的命中检测（Hit Test），当用户点击模型的特定区域（如身体、头部）或任意位置时触发事件。

触发 Vue 状态变更：点击后，通过 Pinia 或 emit 修改一个布尔值（例如 isChatOpen = true）。

遮罩与动画过渡：Vue 监听到 isChatOpen 变为 true，弹出聊天组件（可以通过 `<Transition>` 组件
做个丝滑的淡入或抽屉效果）。


```
src/
├── components/
│   ├── Live2dStage.vue   # 负责 PixiJS 和 Live2D 的渲染
│   └── ChatWindow.vue    # 独立的聊天 Vue 组件
├── store/
│   └── appStore.js       # 存放聊天窗口打开状态、对话记录等
└── App.vue               # 主入口
```

版本兼容问题（重点）：pixi-live2d-display 对 PixiJS 的版本要求比较严格。如果你使用的是 PixiJS v7 或 v8，请务必查看该插件的官方文档，安装对应分支/版本的 npm 包，否则会报各种找不到 Namespace 的错误。

资源跨域与路径：Live2D 模型包含大量的 .json, .moc3, .png 贴图。在本地开发时，建议把模型文件夹放在 Vue 的 public/ 目录下，用绝对路径（如 /live2d/model.model3.json）去请求，避免打包后路径找不到。

性能优化：如果聊天组件打开后不需要看到看板娘，可以在打开聊天时，把 PixiJS 的 app.stop() 掉，或者让渲染层 display: none，关闭 Canvas 的实时渲染，释放手机或低配电脑的 GPU 压力。


业务流水线：大模型接入的三步循环
当用户在你的 Vue 聊天组件里输入一句话并发送时，后端/API 实际上在经历这样一个循环：

```
Plaintext
[用户输入文本] 
      │
      ▼
[1. 组装请求：加上 Prompt(提示词) 和历史记录] 
      │
      ▼
[2. 调用大模型 API (如 DeepSeek、OpenAI)] 
      │
      ▼
[3. 解析返回：提取文本给聊天框，提取表情动作给 Live2D]

```

# 🧩 接入大模型的核心要素


## API Key（通行证）
是什么：你在大模型官方平台（如 OpenAI、DeepSeek、Minimax 等）注册账号后申请的一串密钥。

干嘛用：每次你的程序去找大模型聊天，都要带上这个密钥，证明你是注册用户，大模型才会理你，并从你的账户里扣除相应的 Token 费用。

## Prompt（系统提示词 / 赋予人设）本质skill
这是让你的 Live2D 活过来的关键！大模型默认是一个冷冰冰的 AI，你需要通过 System Prompt 强制给它“洗脑”。

例子：你可以告诉大模型：“你现在是一个傲娇的猫娘，名字叫小咪。你正在和主人聊天。请用傲娇、可爱的语气回答，每句话结尾都要带上'喵'。”

作用：大模型接收到这个设定后，吐出来的文本就会完全符合你 Live2D 看板娘的形象。

## Context（上下文 / 记忆力）
大模型本身是没有记忆的。你对它说“你好”，它回“你好”；你下一句问“我刚才说了什么？”，它就懵了。

怎么解决：每次用户发送新消息时，你的聊天组件需要把之前的聊天历史记录（比如前 5 轮对话），打包和新消息一起发给大模型。这样大模型才能“记住”上文。

## Stream（流式传输 / 打字机效果）
如果不用流式传输：大模型在后台想了 5 秒钟，这 5 秒聊天框一片死寂，5 秒后突然蹦出一整段话。体验很差。

流式传输的效果：大模型想好一个字就吐出一个字，前端聊天框就会像打字机一样一个字一个字地蹦出来。这对于聊天体验至关重要。

🎨 进阶：如何让大模型操控 Live2D？

光是文字聊天不够高级，既然引入了 Live2D，我们要让大模型一边说话，Live2D 一边做动作和表情。

这里常用的高级手法叫做 “结构化输出” 或 “情感标签”。

做法：让大模型在回答的同时，顺便吐出动作指令
你在系统提示词（Prompt）里对大模型做如下规定：

“你在回答时，除了文本，还要根据你当时的心情，在回复前加上 [高兴], [生气], [害羞] 等标签。”
