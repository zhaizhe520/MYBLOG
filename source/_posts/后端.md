```
my-backend/
├── routes/          # 路由层：只负责定义 API 路径（如 /api/chat, /api/user）
├── controllers/     # 控制器层：负责具体的业务逻辑与 req/res 处理
├── services/        # 服务层：调用大模型 SDK、调外部 API 或做复杂计算
├── models/          # 数据层：负责和数据库打交道
├── .env             # 环境变量
└── server.js        # 入口文件：初始化 Express，挂载中间件和路由
```
