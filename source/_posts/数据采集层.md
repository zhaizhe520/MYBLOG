# VNDB API（推荐，干净）

VNDB（The Visual Novel Database）有公开 API，返回 JSON，不用写爬虫：


# python 脚本，20 行就能跑
```
import requests

res = requests.post("https://api.vndb.org/kana/vn", json={
    "filters": ["developer", "=", "yuzusoft"],
    "fields": "title, released, developers.name"
})
for vn in res.json()["results"]:
    print(vn["title"], vn["released"])
```
