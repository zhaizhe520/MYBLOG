# req与res

```
req = 前端发给你的那封信。里面装着三样东西：


app.get('/api/companies/:id/works', async (req, res) => {
  // req.params  = URL 里的变量         /api/companies/1/works  →  { id: '1' }
  // req.query   = URL 问号后面的       ?sort=date&order=desc   →  { sort: 'date', order: 'desc' }
  // req.body    = POST 请求体里的数据   { title: '新作品' }
})
一个请求长这样：


GET http://localhost:3000/api/companies/1/works?sort=date

req.params.id    →  1       ← 路由里 :id 占的坑

req.query.sort   →  'date'  ← 问号后面的

res 就是你写的回信。res.json(rows) = 把查到的数据装进信封寄回去。

就这么简单。前端发请求，req 是拆开的信封，res 是你回信的笔。
```

| 维度         | Java                     | Go                         | Node.js                          |
|--------------|--------------------------|----------------------------|----------------------------------|
| 岗位数量     | 最多（全行业）           | 中等（互联网大厂）         | 少（小型项目）                   |
| 上手难度     | 中等（概念多）           | 简单                       | 极低（前端友好）                 |
| 并发性能     | 良好                     | 顶尖                       | 弱（CPU 不行）                   |
| 部署成本     | 重（虚拟机）             | 极轻（单二进制）           | 中等                             |
| 薪资天花板   | 很高                     | 最高（互联网）             | 中等                             |
| 适用项目     | ERP、电商、金融、大型微服务 | 搜索、网关、云原生、高并发 API | 后台管理、小程序、实时聊天、小型网站 |
