## Map（键值对映射）

相比普通 JavaScript 对象（Object），Map 的键可以是任意数据类型（对象、函数、基本类型都可以），且保持插入顺序。 强引用

```ts
//初始化
const map = new Map<string,number>();

map.set("A",1)//真

console.log(map.get("A"))//查 返回1值
console.log(map.has("A"))//查 返回true 

map.delete("A")//删

//遍历
for(const [key,value] of map){
    console.log(key, value);
}

//高级数学函数 全部相加 纯函数 
const arraySum = Array.from (map.values()) 
```
##  Set（无序唯一值集合）

Set 内部的值必须是唯一的，经常用来做去重或元素存在性判断。

```ts

const set = new  Set<number>([1,2,2,2,3,3,4,5])

console.log(set)//[1,2,3,4,5]

// 2. 增 / 删 / 查
set.add(5);
set.delete(1);
console.log(set.has(3)); // true (时间复杂度 O(1))

//// 3. 集合操作（ES2025 原生方法或手动实现）

const a = new Set ([1,2,3])
const b = new Set ([1,2,3,4])
const c =  new Set ([5,6])

const intersection =  new Set([...a].filter(x=>b.has(x))) //filter()过滤 交集
const difference= new Set ([...a].filter(x=>!b.has(x))) //反向过滤 差集
const union = new Set([...a, ...b]) //并集
```

核心思维：当你发现嵌套循环 $\mathcal{O}(n^2)$ 查找某个数字时，用 Map 把“已经看过”的数据记录下来，下次直接查。 map做纯储

核心思维：使用 Map 作为分类容器，Key 作为分类依据/特征码，Value 存放符合条件的数组  key做指纹

核心思维：不需要知道位置，只需要知道“在不在”时，用 Set.has() 代替 Array.includes()（includes 是 $\mathcal{O}(n)$，Set.has 是 $\mathcal{O}(1)$

# 字符串打乱整合

```ts
function abc (strs: string[]): sting[][]{
    const  map =  new Map<string,string[]>()
    for(const a of strs){
        const k = a.split("").sort().join("");
        if(!map.has(k)){
            map.set(k,[]);
        }
        map.get(k)!.push(a) //! ts的非空
    }
    return Array.from(map.value())
}
//时间繁杂度logk → O (nk logk)
```

```ts
//统计出现的次数，把出现的次数当指纹key
function groupAnagrams(strs: string[]): string[][] {
    const map = new Map<string, string[]>();

    for (const s of strs) {
        // 初始化26个字母计数器，全部置0
        const count = new Array(26).fill(0);
        for (const char of s) {
            // 计算当前字母在a-z中的下标
            //`charCodeAt` 是 **String 原型上的方法**：`String.prototype.charCodeAt()`
            //根源：ASCII 码
            const idx = char.charCodeAt(0) - 'a'.charCodeAt(0);// -97= 1/2/3/4
            count[idx]++;//找到第 idx 号盒子，盒子里面数字加 1 本来全是0 [1,0,0,1,...1]
        }
        // 转字符串作为map的key，例如 "1,0,0,1..."
        const key = count.join(',');//为什么打,? `[12,3].join(',')` → `"12,3"`  `[1,23].join(',')` → `"1,23"` // join("#")
 
        if (!map.has(key)) {
            map.set(key, []);
        }
        map.get(key)!.push(s);
    }
    return Array.from(map.values());
}
//时间复杂度无排序 → O (nk)
```

# 128. 最长连续序列

```ts
function longestConsecutive(nums: number[]): number {
    const set = new Set(nums)
    let c = 0;
    for (const s of set) {
        if (!set.has(s - 1)) {
            let a = s
            let b = 1  // 改这里！起点本身占1个长度
            while (set.has(a+1)) {
                a++
                b++
            }
            c = Math.max(c, b)
        }
    }
    return c;
};
```
