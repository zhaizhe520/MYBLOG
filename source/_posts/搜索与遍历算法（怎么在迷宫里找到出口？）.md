| 维度 | DFS 深度优先 | BFS 广度优先 |
| ---- | ---- | ---- |
| 战术特性 | 一路深挖到底 | 逐层横向遍历 |
| 性格特点 | 一根筋，不撞南墙不回头 | 稳扎稳打，地毯式层层推进 |
| 物理底座 | 栈(Stack) / 递归 | 队列(Queue) / 循环排队 |
| 内存开销 | 比较省，仅记录当前路径 | 比较费，存储整层所有节点 |
| 前端场景 | 提取DOM组件全部子孙节点 | 分层渲染层级菜单 |
