# 向き（むき）・向ける（むける）・向かう（むかう）
## 1. 向かう（むかう）【五段自动词】
含义：朝着、前往；面对面（主体自发朝向，不需要宾语）
例句：
- 駅に向かう。 前往车站。
- 相手に向かう。 面对对方。

## 2. 向ける（むける）【一段他动词】
含义：把…朝向、对准；面向（人为主动把对象指向某处，必须带宾语）
例句：
- カメラを顔に向ける。把相机对准脸部。
- 若者にメッセージを向ける。面向年轻人传递信息。

## 3. 向け（むけ）【名词后缀，取自向ける词干】
文法：～向け
含义：面向…、专为…打造（人为设定目标群体，商品/作品常用）
例句：
- 子ども向けの本 面向儿童的书籍
- 海外向け製品 面向海外的产品

## 4. 向き（むき）【名词后缀】
文法：～向き
含义：适合于、适于（事物本身性质天然匹配，不是专门定制）
例句：
- この家は家族向き。这房子适合家庭居住。
- 夏向きの服 适合夏天的衣服

## 快速区分表
| 词汇 | 词性 | 核心重点 |
| ---- | ---- | ---- |
| 向かう | 自动词 | 自己去往、朝向 |
| 向ける | 他动词 | 人为把A对准B |
| ～向け | 后缀 | 专为XX制作（人为设定对象） |
| ～向き | 后缀 | 本身性质适合XX |
