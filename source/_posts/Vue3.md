computed（计算属性）：

用途：基于现有的响应式变量（ref / reactive）进行纯数学计算或格式化转换（如算坐标、算总价、过滤列表）。

```

```
onMounted（挂载完成生命周期）：

用途：获取真实的 DOM 元素宽高、初始化 PixiJS 画布、绑定原生 window 监听事件（如 addEventListener('resize')）。
```
```
watch（侦听器）：

用途：当变量改变时，去执行有副作用的操作（如重新发送 API 接口请求、播放音效）。
