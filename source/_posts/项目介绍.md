# 实现打字效果

Composable 负责封装跨组件协作的业务

Composable + Pinia 跨组件协作。

三层串联：

第一层：useTypewriter.js — 封装打字逻辑

第二层：live2d组件 — 桥接 Pinia 和打字机

第三层：Pinia petStore — 消息发射塔
 
v-pet-tip 自定义指令（Hover 触发）

DOM 绑定

消息传递


第一步：自定义指令绑定 DOM

第二步：Pinia store 接收消息

第三步：watch 桥接

第四步：打字机逐字输出

第五步：模板渲染气泡

"看板娘的对话系统分三层：触发层用 Vue 自定义指令 v-pet-tip，全局注册，任何元素加一行就能在鼠标移入时自动调用 Pinia store 发出消息。

传递层用 Pinia 做跨组件消息中心，watch 监听消息变化自动桥接。

渲染层用 Composable useTypewriter 封装打字逻辑，setInterval 逐字切割字符串，返回响应式 displayText 驱动模板渲染。

三层之间单向流动——DOM 触发 → Pinia 广播 → Composable 逐字输出，互不耦合。

另外 store 里做了 1.2 秒的防抖——鼠标离开不是立刻消失，给用户预留缓冲时间，两个气泡之间不会闪烁。"
