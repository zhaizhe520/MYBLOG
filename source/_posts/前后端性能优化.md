# vue3性能优化

| 优化手段 | 说明 |
| ---- | ---- |
| v-memo | 缓存DOM子树；依赖数组不变时，diff直接跳过该子树比对，适合超大列表，Vue3 |
| shallowRef / shallowReactive | 浅层响应，仅监听第一层；深层对象不做Proxy代理，减少响应式开销 |
| v-once | 元素只渲染一次，渲染完成后缓存，后续数据更新不再重渲染 |
| 异步组件 + Suspense | 组件异步加载，加载时展示fallback占位，延迟加载组件 |
| KeepAlive | 缓存组件实例，组件切换不销毁重建，保留组件状态，避免重复挂载开销 |
| defineAsyncComponent | 定义异步组件，分包加载，首屏不加载该组件代码 |
| 路由懒加载 | 路由配置里import()，按路由分割代码包，访问路由才加载对应页面代码（代码分割） |
| markRaw | 标记对象永远不被Proxy代理，脱离响应式系统；适合第三方实例、大对象，减少响应式消耗 |
