# <div style="color:red">父组件</div>

<div style="color:red">給组件来赋予动态页面值，實現大量一樣頁面的組件的印刷</div>

<div style="color:pink">组件的属性绑定</div>

`<组件 :pageData="pageAllData[currentPage]" />`

<div style="color:pink">按鈕實現頁面切換</div>

```
<div class="bottom-buttons">
      <button @click="prevPage" :disabled="currentPage === 1">←</button>
      
      <!-- 中間數字：當前頁 / 總頁數 -->
      <div class="page-num">{{ currentPage }} / 4</div>

      <button @click="nextPage" :disabled="currentPage === 4">→</button>
    </div>

```

<div style="color:pink">script裡面來實現數據寫入和函数调用</div>

```
export default {
  components:{
    組件,
  },

  data() {
  return {
    //當前頁碼
    currentPage: 1
    // 所有分页数据
    pageAllData: {
        //頁面1
        1:{
            box1{

            }
            box2{

            }
        }
        //頁面2
        2:{
            box1{

            }
            box2:{

            }
        }
    }
   }
 } 
}
//按钮切换
methods: {
  prevPage() {
    if (this.currentPage > 1) {
      this.currentPage--
    }
  },
  nextPage() {
    if (this.currentPage < 4) {
      this.currentPage++
    }
  }
},
```
# <div style="color:red">子组件接收数据</div>
export default {
  data() {},       // 数据、变量、开关
  methods: {},     // 点击事件、函数
  components: {},  // 子组件
  //傳值
  props: {
  // 接收父组件传过来的、当前这一整页的全部数据
  pageData: {
    type: Object, //對象類型 
    // 默认空对象，防止报错
    default: () => ({})
  }
 },       
}
