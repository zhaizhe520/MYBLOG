# 浏览器引擎

Chromium 的 Browser Process

浏览器引擎层是浏览器的“总调度中心”。它连接用户界面层、渲染引擎层、网络层、JS 执行层。

主要职责

接收用户界面层的指令

<details>
<summary>渲染引擎 (Rendering Engine)</summary>

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>页面标题</title>
  <meta name="description" content="页面描述">
  <meta name="keywords" content="关键词">
  <meta name="author" content="">
  <!-- 禁止移动端自动识别电话邮箱 -->
  <meta name="format-detection" content="telephone=no,email=no">
  <!-- 引入css -->
  <link rel="stylesheet" href="./style.css">
  <!-- favicon -->
  <link rel="icon" href="./favicon.ico">
</head>
```

HTML 解析器遇到`<link>`的时候，**会并行触发资源请求**（预加载扫描器 preloader），预加载扫描器是独立小模块

在 HTML 还没完整解析完的时候，提前捞里面的资源 url，让网络模块提前下载，提升性能。

DOM 树 + CSSOM 树 → Render 树 → Layout → Paint → Composite

```txt
HTML → DOM
CSS → CSSOM
DOM + CSSOM → Render Tree
Render Tree → Layout
Layout → Paint
Paint → Composite
Composite → 屏幕像素    
```

# JavaScript 引擎 (JS Engine)

JS 引擎不是独立进程，和渲染引擎**在同一个渲染进程的主线程**

JS 操作 DOM，本质是调用渲染引擎暴露的 DOM API。
